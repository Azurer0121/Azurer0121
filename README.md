## 项目介绍

### [MDreader](https://github.com/Azurer0121/MDreader)

一个离线优先的本地 Markdown 阅读器，支持 Windows 和 macOS Apple Silicon，界面借鉴 Typora 的克制阅读体验。

- 支持打开或拖拽 `.md`、`.markdown`、`.mdown` 文件
- 支持 CommonMark、GitHub Flavored Markdown、表格、任务列表和代码高亮
- 基于 Milkdown 提供所见即所得编辑、撤销重做和 Markdown 快捷输入
- 支持 Tauri 原生保存、浏览器下载副本和 Markdown 文件关联
- 支持浅色与深色主题，适合日常阅读、编辑和整理 Markdown 文档

欢迎访问 [MDreader 仓库](https://github.com/Azurer0121/MDreader) 查看详细说明。
